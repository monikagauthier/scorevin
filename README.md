# Pacote do site Scorevin

Arquivo: **scorevin-site.zip** — o site pronto para subir em qualquer hospedagem.

1. Baixe e extraia o zip.
2. Envie todo o conteúdo para a pasta principal do site (na Hostinger, HostGator e Locaweb é `public_html`). O `index.html` precisa ficar direto nessa pasta.
3. Abra o seu domínio para conferir.

Esta branch serve só para download. O site continua sendo editado na branch `main`.
